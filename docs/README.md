# Homato Documentation

This folder contains comprehensive documentation for the Homato Home Automation System.

## Documentation Structure

- **[overview.md](overview.md)** - System architecture, components, and key features
- **[installation.md](installation.md)** - Installation instructions for all components
- **[firmware.md](firmware.md)** - Firmware setup, flashing, and configuration
- **[hardware.md](hardware.md)** - Hardware components, wiring, and safety guidelines
- **[ble-pairing.md](ble-pairing.md)** - BLE pairing process and mobile app integration
- **[api.md](api.md)** - API documentation and MQTT topic structure
- **[configuration.md](configuration.md)** - System configuration options
- **[troubleshooting.md](troubleshooting.md)** - Common issues and solutions

## Recent Updates

The documentation has been updated to reflect the following changes:

1. **Bluetooth Configuration** - Added BLE support for device pairing and configuration
2. **Multiple WiFi Network Support** - Implementation of storage for up to 3 WiFi credentials
3. **ESP32 Migration** - Updated hardware from ESP8266 to ESP32
4. **Partition Scheme** - Added huge_app partition scheme requirements
5. **Memory Optimization** - Techniques to reduce firmware memory usage
6. **Mobile App Integration** - Documentation for backend team to implement mobile app pairing

## Contributing to Documentation

When updating documentation, please ensure:
1. All code examples are up-to-date
2. Hardware specifications reflect current components
3. Configuration examples match the current codebase
4. Installation instructions are verified to work
